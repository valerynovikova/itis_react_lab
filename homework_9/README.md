# Переключение Тем в React Native

## Описание

В данном проекте реализовано локальное переключение тем (светлая и темная) в приложении на React Native. Пользователь может переключать темы с помощью кнопки "Переключить тему", что меняет цветовую схему интерфейса приложения.

## Функциональность

1. Переключение тем: При нажатии на кнопку "Переключить тему" приложение изменяет текущую тему с светлой на темную и наоборот.

## Использование

- Компонент App оборачивается в ThemeProvider, который предоставляет контекст для текущей темы и возможность переключения.
- Пользовательский хук useTheme используется в компонентах для доступа к текущей теме и функции переключения.
