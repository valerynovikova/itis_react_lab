# itis_react_lab

## Описание

Этот репозиторий предназначен для учебных проектов по React Native, созданных в рамках практических заданий. Он содержит примеры реализации различных приложений, списки задач и другие интерфейсы, которые демонстрируют использование React Native и связанных технологий.

### Цели проекта
- Ознакомление с основами разработки мобильных приложений на React Native.
- Практика работы с компонентами, навигацией и состоянием приложения.
- Изучение использования библиотек для управления состоянием, таких как MobX.
- Разработка и тестирование пользовательского интерфейса.

### Структура репозитория
- /src: Основная папка с исходным кодом приложений.
    - /components: Компоненты React Native.
    - /stores: MobX хранилища для управления состоянием.
- App.js: Главный файл приложения.
- index.js: Точка входа приложения.

### Как запустить проект
1. Убедитесь, что у вас установлен Node.js и React Native CLI.
2. Склонируйте репозиторий:

   git clone https://github.com/yourusername/itis_react_lab.git

3. Перейдите в папку проекта:

   cd itis_react_lab

4. Установите зависимости:

   npm install

5. Запустите приложение на эмуляторе или реальном устройстве:

   npx react-native run-android

   или

   npx react-native run-ios
